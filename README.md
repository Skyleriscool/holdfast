# Holdfast

A browser tower-defense game. Creeps follow a marsh road from a blight rift to the citadel gate. Place towers on the grass, earn gold from kills, and hold the line through escalating waves.

## Play

- Place **Sentry**, **Mortar**, **Rime**, and **Lance** towers. Each has its own range, cost, and shot.
- Spend gold to upgrade **damage** and **fire rate**.
- Change targeting: First, Last, Close, or Strong.
- Send the next wave, pause, or run at 2× speed.
- Lives, gold, and the current wave stay on screen. Clear every wave to win, or restart after a loss.

Best score is saved in the browser.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on port 8080.

```bash
npm run typecheck
npm run build
```
